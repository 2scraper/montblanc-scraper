Montblanc Scraper

Open-source Montblanc scraper for montblanc.com — three engines, your own infrastructure by default, and 2Captcha's paid products only where they actually buy you something.

Category listings, keyword searches and full product pages: name, sku, price, currency, stock, collection, colour, images and every variant of a product with its own price — into JSON or CSV.

What was actually measured

You do not need an account, a key or a proxy to scrape this site.

Measured on 2026-09-17 from a bare datacenter address (Hetzner, Helsinki) with no credentials configured at all: category listings, keyword searches and product pages all answered HTTP 200. No reCAPTCHA, hCaptcha, Turnstile, DataDome, PerimeterX, Incapsula, Kasada or AWS WAF markers appeared on any capture, and there is no data-sitekey anywhere on the site.

We say that plainly instead of selling around it. What the paid products buy on this site is a specific market: Montblanc serves every market from one host with the locale in the URL path, and it sets prices per market rather than converting them — one backpack was EUR 2000 on en-fi, EUR 1900 on de-de, GBP 1700 on en-gb and USD 1990 on en-us. Two of those share a currency and still disagree. They also buy volume from many addresses, and not having to run a browser at all.

What you get

Three engines, one schema

Playwright (primary, with parallel page fetching), Selenium and Puppeteer via pyppeteer — identical rows and exit codes — plus a browserless client for 2Captcha's Scraping Browser API.

Three modes

A category listing, a keyword search, or a single product page — and that last one emits one row per variant, so a sixteen-nib Meisterstück is sixteen rows.

Structured data first

Reads Montblanc's own ItemList and ProductGroup, enriched from the site's tile attributes, with a URL-pattern fallback — no fragile CSS-class scraping.

JSON, CSV and a sidecar

One stable row schema, plus a .meta.json per run recording the market, the ordering, the site's own totals and which pages failed by number.

Honest diffs

diff_runs.py refuses a comparison across markets, modes or orderings, because each changes which products are in the file.

A canary with no secrets

A real 3-page scrape runs daily from a bare CI runner — which is also what keeps the claim above honest.

Traps it already handles

1. A product page publishes ProductGroup, not ItemList

Point a listing parser at one and it silently returns the “you may also like” carousel as the page's products.

2. Stock cannot be read from the structured data

availability said InStock on 192 of 192 rows measured, while the tiles said sold-out on 7 of 384. The tile is what this scraper reads.

3. “From €515” is a minimum, not a price

A variant group's price range is recorded as a minimum and labelled price_source: "dom_range".

4. The edge refuses HTTP client libraries by killing the connection

requests reports that as a read timeout, which looks exactly like a slow network and is not one.

Get started

git clone https://github.com/2scraper/montblanc-scraper.git
cd montblanc-scraper
pip install -r requirements.txt -r requirements-playwright.txt
playwright install chromium

python playwright_scraper.py \
    --url "https://www.montblanc.com/en-us/writing-instruments" \
    --pages 3 --format both

No key, no proxy, no account. Output lands in montblanc_products.json, montblanc_products.csv and a .meta.json sidecar.
